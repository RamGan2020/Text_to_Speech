# Text-to-Speech / Speech-to-Text Web Application

Web-приложение для синтеза речи (TTS) и распознавания речи (STT) с использованием нейросетевых моделей Silero TTS v4 и OpenAI Whisper. Позволяет озвучивать текст в MP3, распознавать загруженные аудиофайлы в текст, а также записывать речь с микрофона и сразу распознавать её.

## Особенности

- ✅ Бесплатно и полностью локально (без внешних API)
- ✅ Нет ограничений на длину текста
- ✅ Русский язык (5 голосов: 3 женских, 2 мужских)
- ✅ Простой и понятный интерфейс с вкладками
- ✅ Автоматическая разбивка длинных текстов на чанки
- ✅ Воспроизведение и скачивание MP3
- ✅ Настройки TTS: выбор голоса, ударения, буква «ё»
- ✅ Распознавание MP3, WAV, OGG, FLAC в текст
- ✅ Запись речи с микрофона прямо в браузере
- ✅ Конвертация записи из webm в WAV без ffmpeg (через AudioContext)
- ✅ Копирование распознанного текста в буфер обмена

## API-документация

### POST /synthesize

Синтез речи из текста (TTS).

**Request body (JSON):**
```json
{
  "text": "Пример текста для озвучивания",
  "speaker": "kseniya",
  "put_accent": true,
  "put_yo": true,
  "podcast_mode": false
}
```

| Поле | Тип | По умолчанию | Описание |
|------|-----|--------------|----------|
| text | string | — | Текст для озвучивания (обязательное) |
| speaker | string | kseniya | Голос: kseniya, xenia, baya, aidar, eugene |
| put_accent | boolean | true | Расстановка ударений |
| put_yo | boolean | true | Замена «е» на «ё» |
| podcast_mode | boolean | false | Включает режим подкаста с тегами `[voice:...]` и `[pause:...]` |

**Response:** MP3-файл (`audio/mpeg`)

**Ошибки:**
- `400` — пустой текст
- `500` — ошибка синтеза

---

### POST /transcribe

Распознавание речи из аудио-файла (STT).

**Request (multipart/form-data):**
```
audio: файл (MP3, WAV, OGG, FLAC, WEBM)
```

**Response (JSON):**
```json
{
  "text": "Распознанный текст из аудио",
  "filename": "записанная_речь.mp3"
}
```

**Ошибки:**
- `400` — файл не загружен или неподдерживаемый формат
- `500` — ошибка распознавания

---

### GET /health

Проверка работоспособности.

**Response:** `{"status": "ok"}`

## Podcast Mode (TTS)

`podcast_mode` включает специальный разбор тегов в тексте и позволяет:
- переключать голос по ходу текста;
- вставлять паузы заданной длины.

### Поддерживаемые теги

- `[voice:kseniya]`, `[voice:xenia]`, `[voice:baya]`, `[voice:aidar]`, `[voice:eugene]`
- `[pause:1.5]` или `[pause:1.5s]` — пауза в секундах (можно дробное значение)
- `[pause:500ms]` — пауза в миллисекундах

### Пример текста

```text
[voice:kseniya] Всем привет! Это наш подкаст.
[pause:0.8]
[voice:aidar] Сегодня обсудим новости по проекту.
[pause:1.2]
[voice:kseniya] Поехали!
```

### Использование в UI

1. Откройте вкладку «Текст в речь».
2. Включите переключатель «Режим подкаста (теги [voice:] и [pause:])».
3. В блоке «Примеры для вставки» нажмите нужный шаблон (он вставится в поле текста).
4. Нажмите «Обработать» для синтеза.

## Как работает синтез речи (TTS)

1. Пользователь вводит текст → нажимает «Обработать»
2. Frontend отправляет POST-запрос с настройками на `/synthesize`
3. Backend разбивает текст на чанки (до 500 символов)
4. Для каждого чанка модель Silero TTS v4 генерирует аудио-тензор
5. Тензоры объединяются в один аудио-поток
6. Аудио сохраняется как MP3 и отправляется обратно
7. Frontend показывает плеер и кнопку скачивания

## Как работает распознавание загруженного файла (STT)

1. Пользователь выбирает аудио-файл → нажимает «Распознать файл»
2. Frontend отправляет файл через `FormData` на `/transcribe`
3. Backend сохраняет файл во временный файл (для корректного определения формата)
4. librosa загружает аудио, конвертирует в моно
5. Аудио ресемплится до 16kHz через librosa.resample
6. Данные передаются в Whisper как numpy массив (float32)
7. Whisper распознаёт текст и возвращает результат
8. Frontend показывает текст в поле и кнопку «Копировать»

## Как работает запись с микрофона

1. Пользователь нажимает «Начать запись»
2. Браузер запрашивает разрешение на доступ к микрофону
3. `MediaRecorder API` начинает запись в формате `audio/webm`
4. Отображается пульсирующий индикатор и таймер длительности
5. При нажатии «Остановить»:
   - `AudioContext.decodeAudioData()` декодирует webm в AudioBuffer
   - Функция `audioBufferToWav()` конвертирует AudioBuffer → WAV Blob:
     - Интерливинг каналов (чередование левого/правого)
     - Конвертация float32 → int16
     - Ручная запись WAV заголовка (44 байта) + аудио-данные
6. Появляется аудиоплеер для прослушивания записи
7. При нажатии «Распознать запись» → отправка WAV на `/transcribe`
8. Результат отображается в поле с текстом

## Ограничения моделей

### Silero TTS v4
- Поддерживает тексты до ~500 символов за один вызов
- При длинных текстах сервис автоматически разбивает на чанки
- Паузы между предложениями сохраняются внутри чанка

### Whisper small
- Модель требует ~500 МБ оперативной памяти
- Распознавание длинных файлов может занять время
- Максимальный размер файла: 25 МБ
- M4A не поддерживается (требуется ffmpeg)

### Запись с микрофона
- Зависит от поддержки MediaRecorder API браузером
- Запись происходит в формате webm, конвертация в WAV — в браузере
- Требуется разрешение пользователя на доступ к микрофону
- Работает в Chrome, Firefox, Edge (не поддерживается в Safari < 14.1)
