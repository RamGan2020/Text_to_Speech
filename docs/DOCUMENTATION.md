# Text-to-Speech Web Application

Web-приложение для синтеза речи (text-to-speech) с использованием нейросетевой модели Silero TTS v4. Позволяет ввести текст любой длины и получить MP3-файл с озвучкой.

## Особенности

- ✅ Бесплатно и полностью локально (без внешних API)
- ✅ Нет ограничений на длину текста
- ✅ Русский язык (5 голосов: 3 женских, 2 мужских)
- ✅ Простой и понятный интерфейс
- ✅ Автоматическая разбивка длинных текстов на чанки
- ✅ Воспроизведение и скачивание MP3
- ✅ Настройки: выбор голоса, ударения, буква «ё»

## API-документация

### POST /synthesize

Синтез речи из текста.

**Request body (JSON):**
```json
{
  "text": "Пример текста для озвучивания",
  "speaker": "kseniya",
  "put_accent": true,
  "put_yo": true
}
```

| Поле | Тип | По умолчанию | Описание |
|------|-----|--------------|----------|
| text | string | — | Текст для озвучивания (обязательное) |
| speaker | string | kseniya | Голос: kseniya, xenia, baya, aidar, eugene |
| put_accent | boolean | true | Расстановка ударений |
| put_yo | boolean | true | Замена «е» на «ё» |

**Response:** MP3-файл (`audio/mpeg`)

**Ошибки:**
- `400` — пустой текст
- `500` — ошибка синтеза

### GET /health

Проверка работоспособности.

**Response:** `{"status": "ok"}`

| Параметр | Описание |
|----------|----------|
| put_accent | Расстановка ударений — улучшает произношение сложных слов |
| put_yo | Автоматическая замена «е» на «ё» — корректное произношение |

## Как работает синтез

1. Пользователь вводит текст → нажимает «Обработать»
2. Frontend отправляет POST-запрос на `/synthesize`
3. Backend разбивает текст на чанки (до 500 символов)
4. Для каждого чанка модель Silero TTS генерирует аудио-тензор
5. Тензоры объединяются в один аудио-поток
6. Аудио сохраняется как MP3 и отправляется обратно
7. Frontend показывает плеер и кнопку скачивания

## Ограничения модели

- Silero TTS v4 поддерживает тексты до ~500 символов за один вызов
- При длинных текстах сервис автоматически разбивает на чанки
- Паузы между предложениями сохраняются внутри чанка
